# Car Match Assistant Recommendation Server - Backend

## Overview

The backend powers the recommendation engine for Car Match Assistant.

It exposes APIs that:

* Serve the car dataset
* Accept user preferences
* Calculate recommendation scores - a complete logic calculation and sorting top 3 recommendations
* Return the top matching vehicles

The backend uses a rule-based recommendation engine instead of external AI services to keep the MVP deterministic, explainable, and cost-free.

---

## What I Built

### Car Dataset API

Provides vehicle information including:

* Make
* Model
* Price
* Mileage
* Safety rating
* Fuel type
* Seating capacity
* Specs
* Technical specifications

### Recommendation Engine

The recommendation engine evaluates vehicles using a weighted scoring model.

Scoring categories:

| Category        | Weight |
| --------------- | ------ |
| Budget Match    | 40     |
| Priority Match  | 30     |
| Fuel Type Match | 20     |
| Seating Match   | 10     |

Total Score: 100

The system ranks vehicles by score and returns the top recommendations.

## Tech Stack

### Node.js

Chosen for:

* Fast development
* Shared JavaScript ecosystem
* Easy frontend/backend interoperability

### Express.js

Used for:

* Lightweight REST APIs
* Simple routing
* Minimal overhead
* Easy CORS integration

### JSON Dataset

Used instead of a database because:

* Small dataset size
* Faster MVP development
* Easier local setup
* No infrastructure dependencies

## API Endpoints

### Get Cars

GET /api/cars

Returns all available vehicles.

---

### Get Recommendations

POST /api/recommendations

Request:

```json
{
  "budget": 1500000,
  "fuelType": "Petrol",
  "seats": 5,
  "priority": "Safety"
}
```

Returns top matching vehicles based on weighted recommendation scoring.
